# Uji skenario (UAT) bot CP Live

Dijalankan **bersama pengembang** di grup WhatsApp uji, setelah `docs/panduan-vps.md` langkah 1–10 selesai (`smoke:extract` lulus). Untuk setiap skenario: jalankan **Langkah**, bandingkan dengan **Hasil yang diharapkan**, isi **Hasil nyata** dan **Lulus?** (Ya/Tidak). Semua skenario harus lulus sebelum go-live; skenario yang gagal kembali ke pengembang beserta bukti (tangkapan layar, isi log).

## Persiapan

- Jadwal aktif (Pengaturan B2) = **TIDAK**; target bulan ini, dua host (mis. Brando dan Vanna) beserta No WA, No WA owner, dan Email owner sudah terisi.
- Siapkan beberapa screenshot data live asli (TikTok dan Shopee) dari dua host, termasuk satu **layar akhir** (live sudah ditutup).
- Perintah berguna di VPS (jalankan dari `~/cp-sistem/deploy`):
  - log bot: `docker compose logs --tail 100 bot`
  - hentikan bot: `docker compose stop bot` · nyalakan: `docker compose start bot`
- Tab yang diperiksa: **Sesi Live**, **Data Kredit**, **Koreksi & Atribusi**, **Gangguan**, **Kehadiran**, **Target Harian**, **Dashboard Host**, **Log Bot**, **Heartbeat**. Dashboard diperbarui bot tiap 15 menit.
- Teks tanda terima bot: `✅ Tercatat — NAMA · Shopee +RpX · TikTok +RpY · Balas kalau angka salah`.

## Setelah semua skenario lulus

- [ ] Kembalikan pengaturan uji (Batas jeda B7 = `240`, `.env` memakai key Claude yang benar).
- [ ] Hapus atau abaikan baris uji di Sesi Live/Data Kredit sesuai kesepakatan (mintalah bantuan pengembang; jangan menghapus baris tanpa panduan karena tabel urut tanggal). **Setelah menghapus baris uji di Sheets, jalankan `docker compose restart bot`** (bot menyimpan ukuran tab di memori).
- [ ] **Go-live:** pindahkan bot ke grup **CP Live** yang asli. Masukkan nomor bot ke grup itu, ambil ID grupnya (panduan VPS 4d), ganti `LIVE_GROUP_ID` di `.env`, lalu:

```bash
cd ~/cp-sistem/deploy && docker compose up -d --force-recreate bot
```

- [ ] Pastikan **Jadwal aktif = TIDAK** di Pengaturan B2 pada hari pertama.
- [ ] Bagikan `docs/panduan-host.md` ke para host di grup.
